# Adventurer Roster

React + TypeScript + Vite assignment scaffold.

## Run

```sh
npm install
npm run dev
```

The initial page is intentionally blank. The entry point is ready, and the assignment components are left for implementation.

```sh
npm run build
npm run lint
```

## File map

- `src/components/Character.tsx`: props type and reusable character card.
- `src/App.tsx`: roster heading and at least four uses of Character with different props.
- `src/App.css`: roster and card styling.
- `src/index.css`: global page styling.
- `src/main.tsx`: React entry point; connect App after creating it.

## Requirements

- Show an Adventurer Roster heading.
- Use one reusable Character component with name, character class, level, and health.
- Define a TypeScript props type and destructure the props.
- Render at least four different characters and display all their information.
- Style each character as a simple card.
- Optional bonus: a title displayed only when provided.

Assignment: https://snow.instructure.com/courses/1247151/assignments/19218007

Due September 17, 2026 at 11:59 p.m. Submission: Text or Web URL.

## Learning workflow

Use scaffold_then_guide: the scaffold provides configuration and empty files; the student implements each requirement with guidance.
